# 01-bresenham — Bresenham 画线（1962）

## 问题

屏幕是整数网格，直线是连续的。给定两个整数端点，
要选出一串像素让它们"看起来像"那条直线。

朴素做法是沿 x 走一步、算 `y = y0 + (x - x0) * dy / dx`、四舍五入。
正确，但每个像素一次除法 —— 在 1962 年的硬件上，这是不可接受的。

## 想法

Jack Bresenham 在 IBM 给绘图仪写控制程序时发现：
**你根本不需要知道 y 是多少，只需要知道"该不该往上走一格"。**

那个判断可以用一个整数累加器维护。设当前像素到真实直线的垂直偏差为 `e`，
走一步 x，`e += dy/dx`；当 `e >= 1/2` 时上面那个像素更近，`y += 1` 且 `e -= 1`。

`dy/dx` 和 `1/2` 都是分数，但两边同乘 `2*dx`（正数，不改变不等号方向）
之后全部变成整数：

```
e >= 1/2      ⟺   2*dx*e >= dx
e += dy/dx    ⟺   (2*dx*e) += 2*dy
```

令 `err = 2*dx*e`，整个判定只剩整数加减和一次比较。
**除法和浮点从此消失，而且是精确的，不是近似的** ——
这条线上没有任何舍入误差可以累积。

这是计算机图形学里最早、也最能说明问题的一个例子：
把"求值"换成"增量判定"。后面的深度插值、纹理坐标插值、
扫描线填充，用的都是同一个思路。

## 八个卦限：为什么用对称形式

上面的推导只对 `dx >= dy >= 0` 成立。教科书常见做法是"交换 x/y、
取反符号"把另外七种情况映射回来，写出来是一堆分类讨论。

本实现同时维护两个方向的判别式，每步各自决定要不要走，
天然覆盖八个卦限。代价是每步多一次比较、一次移位。

换来的不只是短：**没有分支表就没有"某个卦限漏了"这类 bug**。
而那正是这个算法最经典的错误形态 —— 七个方向都对，第八个差一格,
只在特定斜率下出现。

有一个坑值得单独记：两个判定必须都用**进入本轮时**的 `e2`。
写成两个连续的 `if` 并在第一个里改 `err`，会在 45 度线上少走一格 ——
症状只在 `|dx| == |dy|` 时出现。`tests/` 里有专门的用例。

## 和下一课的关系

Bresenham 的输出是**硬边**的：每个 x 只点一个像素，非黑即白，放大看是阶梯。

1991 年 Xiaolin Wu 的算法在同一个增量框架上，把误差项 `err` 直接
**当作覆盖率**用：同时点上下两个像素、按误差分配亮度。那就是抗锯齿版本。

所以这两节课的关系不是"简单版和高级版"，而是**同一个判别式的两种读法**：
一个拿它做决策，一个拿它做权重。

## 裁剪

端点可以在屏幕外。本实现的做法是逐像素边界检查
（`Surface::put()` 越界即丢弃），外加一个整数 outcode 平凡拒绝。

正确，但对一条从 `(-10^6, 0)` 到 `(10^6, 0)` 的线仍然要走两百万步。
正确的解法是先做 Cohen–Sutherland 裁剪再光栅化，那是后面的课。

**而且那两者的结果未必逐像素相同** —— 裁剪把端点挪到边界上，
判别式的初值随之改变，靠近边界的几个像素可能选得不一样。
这不是 bug，是"先裁剪"与"后裁剪"两种流水线的固有差异。

## 画面怎么看

三块，各自对应一类容易出错的地方：

- **辐条轮盘**（中央）：从中心向 180 个方向各画一条等长的线，
  八个卦限全覆盖。哪个卦限写错了，轮盘上就会缺一块、多一块，
  或者某段密度明显不同 —— 一眼可见。
- **左上角的一束线**：接近水平（`dy` 很小）、接近垂直（`dx` 很小）、
  正好 45 度（`dx == dy`）。这三个是判别式的边界情况。
- **横穿整个画面的蓝线**：两个端点都在画布外，验证裁剪路径。

辐条端点用 `sin`/`cos` 算，**那是在构造输入，不在光栅化里**。
线一旦有了两个整数端点，从那里到像素之间没有任何浮点。

## 不变量

`tests/test_line.cpp`，94 条检查：

| 性质 | 抓什么 |
| --- | --- |
| 端点必被画上，且是首尾 | 起止条件写反 |
| 相邻像素 8-连通 | 某个卦限一步走两格 |
| 无重复像素 | 判别式更新顺序错 |
| 步数 = `max(\|dx\|,\|dy\|)+1` | 差一错误 |
| 正反向像素**集合**相同 | 平局规则不对称 |
| 不写出 `width()` 之外 | 用 `width*4` 当行跨距 |

注入六种典型错误，六种全被抓到 —— 其中四种表现为**根本不返回**
而不是画错。详见 `docs/architecture.md` 第 5 节。
